# Assignment 01 - Overview

Learning goals:
- Practice basic Python syntax and small utilities.
- Work with simple scripts and functions.
- Get introduced to Prefect (small warmup examples included).

Files:
- warmups_01.py — short warmup exercises.
- project_01.py — larger project script for the week.
- hello_prefect.py, prefect_warmup.py — small Prefect examples.
- data/ — example datasets used by the exercises.

How to run:
- Run warmups and projects with `python warmups_01.py` or `python project_01.py` from this directory.
- Prefect examples require the `prefect` package (see top-level requirements.txt).
